# Paradise Nursery Shopping Application

Paradise Nursery is a React-based e-commerce application designed for plant enthusiasts to browse and purchase houseplants.

## Features
- **Landing Page**: Welcome page featuring company background and a quick entry button.
- **Product Listing**: Plants organized into categories with dynamic "Add to Cart" functionality.
- **Shopping Cart**: Interactive cart with options to adjust item quantities, calculate sub-totals/totals, and remove items.
- **Redux State Management**: Centralized store handling cart state seamlessly across components.

## Tech Stack
- React
- Redux Toolkit
- CSS3 / HTML5
